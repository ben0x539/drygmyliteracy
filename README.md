# Drygmy Literacy

This Minecraft mod is an Ars Nouveau addon with a single mechanic:
When a Drygmy Henge generates items, a Book & Quill in an adjacent Lectern will list which entity contributed that item to the loot table.

For server play, Drygmy Literacy only needs to be installed on the server, it has no client-side functionality.

Drygmy Literacy was developed for Ars Nouveau 5.10.6 on NeoForge 21.1.219 (Minecraft 1.21.1).
I don't know anything about version compatibility.
Good luck!

## Limitations

Drygmy Literacy runs on the server side and inserts plain text into a vanilla Book & Quill.
The generated text does not take into account a player's language settings: all entity and item names will be in English.
Additionally, line-wrapping will be inappropriate for players a different font with different character widths.

## Why are we doing this?

I had a couple dozen mob jars in my Drygmy farms and I kept getting some random bullshit items I didn't care for and because so many mobs were from mods I barely even touched and probably had stuff added to their loot tables from a dozen other mods I had no idea which mobs to remove to get those drops out of the combined loot table.

So I figured I'd have the Drygmys tell me.
